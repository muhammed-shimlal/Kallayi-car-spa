# Contributor Code of Conduct

## Our Pledge

We, as contributors and maintainers of **Kallayi Car Spa**, are committed to making participation in this project a welcoming, respectful, and harassment-free experience for everyone.

We pledge to foster an open, inclusive, and collaborative environment regardless of:

- Experience level
- Education
- Nationality
- Personal appearance
- Race
- Religion
- Gender identity or expression
- Sexual orientation
- Disability
- Age

Everyone should feel comfortable contributing to this project.

---

# Our Standards

Examples of behavior that contribute to a positive environment include:

- Being respectful and professional.
- Giving and accepting constructive feedback.
- Helping new contributors.
- Respecting different viewpoints.
- Focusing on what benefits the project.
- Taking responsibility for mistakes.
- Collaborating in good faith.
- Keeping discussions productive.

---

# Unacceptable Behavior

The following behaviors are not acceptable:

- Harassment or discrimination of any kind.
- Personal attacks or insults.
- Trolling or inflammatory comments.
- Hate speech.
- Threats or intimidation.
- Publishing someone else's private information without permission.
- Spam or malicious content.
- Knowingly introducing malicious code.
- Any illegal activity related to the project.

---

# Scope

This Code of Conduct applies to all project spaces, including:

- GitHub Issues
- Pull Requests
- Discussions
- Documentation
- Project Wiki
- Community communications related to the project

---

# Responsibilities

Project maintainers are responsible for:

- Enforcing this Code of Conduct fairly.
- Addressing inappropriate behavior.
- Reviewing reported incidents.
- Taking appropriate action when necessary.
- Maintaining a welcoming environment for contributors.

---

# Reporting Issues

If you experience or witness behavior that violates this Code of Conduct, please report it privately to the project maintainer through GitHub.

When reporting an issue, include:

- A description of the incident.
- Relevant links or screenshots (if available).
- Any additional context that may help with the investigation.

All reports will be handled respectfully and, where possible, confidentially.

---

# Enforcement

Project maintainers may take appropriate actions in response to unacceptable behavior, including:

- Warning the contributor.
- Removing inappropriate comments or content.
- Temporarily restricting participation.
- Permanently banning individuals from contributing to the project.

The action taken will depend on the severity and context of the violation.

---

# Community Guidelines

We encourage contributors to:

- Ask questions respectfully.
- Share ideas openly.
- Provide helpful feedback.
- Write clear documentation.
- Follow project conventions.
- Review code constructively.
- Respect maintainers' decisions.

---

# Best Practices

Before submitting a contribution:

- Read the project documentation.
- Follow the contribution guidelines.
- Test your changes.
- Keep pull requests focused.
- Write clear commit messages.
- Update documentation when necessary.
