# 📌 Project Overview

Kallayi Car Spa is a Vehicle Wash Management System built using Django and Django REST Framework. The goal of this project is to provide a complete backend solution for managing a car wash business, including customers, vehicles, services, staff, bookings, and financial records through a secure REST API.

---

# 🎯 Project Goals

- Build a secure REST API
- Simplify vehicle wash business operations
- Manage customers and vehicles
- Track services and bookings
- Record financial transactions
- Support scalable future development
